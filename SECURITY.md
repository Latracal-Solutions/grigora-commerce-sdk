# Security policy

## Reporting a vulnerability

Please email **security@grigora.co** with a description, steps to reproduce, and the affected package and version. Do not open a public issue for security reports. We aim to acknowledge within two business days and to ship a fix, or a mitigation and timeline, within thirty days for confirmed issues.

## Scope

This repository contains browser-side SDK code. Payment secrets, order state and pricing live in the Grigora API, which is outside this repository; reports about the API are welcome at the same address.

## Supported versions

The latest minor release of each package receives security fixes. Older majors receive fixes for six months after the next major is released.
